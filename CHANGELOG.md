# Changelog

## 1.2.0

Added support for more Minecraft versions: **1.20.1, 1.20.4, 1.20.6, 1.21.1, 1.21.4 and 1.21.8**.

## 1.1.0

- Import zipped worlds directly, no unzipping first
- Drag and drop a world folder or zip onto the game window
- Import progress screen with a Done button
- Buttons added to the Create New World screen

## 1.0.0

- Open World Folder and Import World buttons on the Select World screen
