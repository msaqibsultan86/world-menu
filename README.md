# World Menu

Adds two handy buttons to Minecraft’s Select World screen:

* **Open World Folder** — quickly opens the instance’s `saves` folder.
* **Import World** — select a world folder from anywhere on your PC. The mod checks for `level.dat` and copies the world into your `saves` folder.

Client-side only, with no configuration needed.

**Minecraft:** 1.21.1
**Loader:** Fabric
**Requires:** Fabric API

## Building

Run:

```text
gradlew build
```

The finished jar will be in `build/libs`. The project uses Java 21.
